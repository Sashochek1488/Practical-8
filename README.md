# HOMERENTER
---

## Опис

Homerenter дозволяє користувачам:

- **переглядати доступне житло**;
- **шукати житло за містом або ціною**;
- **бронювати квартири та будинки**;
- **переглядати детальну інформацію про житло**;
- **працювати з демо-версією додатку**.

___
## Технології

- **Java**;
- **Spring Boot**;
- **Angular**;
- **HTML/CSS**.

___
## Встановлення

### 1. Клонування репозиторію

```bash
git clone https://github.com/your-username/homerent.git
```

### 2. Перехід у директорію проєкту

```bash
cd homerent
```

### 3. Запуск бекенду

```bash
cd backend
./mvnw spring-boot:run
```

### 4. Запуск фронтенду

```bash
cd frontend
npm install
ng serve
```
___
## Використання

Після запуску відкрийте браузер:

```text
http://localhost:4200
```

Демо-функції:
- перегляд житла;
- фільтрація оголошень;
- бронювання житла;
- тестовий акаунт користувача.
